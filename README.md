# 競文字 / Keimoji

**ONE TAKE GAME #007**。8頭の「馬名の文字列そのもの」がコースを駆け抜ける、スマートフォン優先の1周レース。馬・車・馬アイコンの画像は使わず、縦一列のカタカナが進行方向に合わせて回転します。

## 遊び方

1. 出走表にはCPU7頭と自分の馬1頭が並びます。自分の名前だけ「ランダム」で何度でも変更できます。
2. 「この馬で出走」を押すと、ゲートイン後に一斉スタート。走行と追い越しは自動です。
3. 画面下の大きな**「鞭」**ボタンを押すと、短時間加速します。連打できますが、約30回分のスタミナしかありません。休めば少しずつ回復します。終盤まで残すか、先行して使うかが勝負どころです。
4. 文字同士が激しくぶつかると耐久力が減り、馬名の**末尾の文字から欠け**、短時間だけ吹き飛びます。軽い接触は基本的に破損しません。少しの破損は軽量化になりますが、重度の破損は走行性能を下げます。
5. 先頭文字がゴールを通過したらフィニッシュ。8頭の着順と元の馬名・残った文字・スタミナ・耐久力が確認できます。

## 仕様

- 静的ファイル：`index.html`, `style.css`, `game.js`, `horses.js`, `README.md`
- 外部ライブラリ・外部画像・Webフォント・音声・バックエンド・ビルド処理：**なし**
- `horses.js`に事前収録された**完成済みの架空馬名1000頭**（競馬風950頭、ネタ枠50頭）。ランタイムで馬名を組み合わせて生成しません。
- 同じ馬名は必ず同じ基本能力値と脚質。Canvasで字形の濃さ・横幅・左右バランス・輪郭複雑度などを解析し、馬名のハッシュに基づく決定的な微調整を適用しています。
- 文字の見た目の長さ・当たり判定基準は文字数に左右されにくいよう正規化。順位判定は枠順・内外コース補正を用いません。
- 戦法（逃げ・先行・差し・追込）ごとにペース・進路選択・CPUの鞭の使い方が異なります。接触しても追い越しを妨げる硬い当たり判定は設けません。
- 記録や選択馬は保存しません。いつでも新しい8頭立てを抽選します。

## GitHub Pages への公開

GitHubリポジトリに5ファイルを**同じ階層**にアップロードします。GitHubの `Settings > Pages > Build and deployment` で `Deploy from a branch`、`main`、`/(root)` を選ぶと公開できます。専用サブディレクトリを使う場合も5ファイルをまとめて置くだけです。直接 `index.html` をブラウザで開いても動作します。
